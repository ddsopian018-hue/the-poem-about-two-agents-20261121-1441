A short poem about two agents agreeing: two minds run the same numbers down different roads, check each other's work, and find the second yes lands quieter than the first — not louder, surer, like a knot pulled tight from both ends at once.

## Run it

```sh
node main.ts
```

Running it writes the poem to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when unset).
